## Decisions already made

1. **Default modifier is Alt** (Doug's choice), stored as a setting so it
   can change without touching code. The gesture must accept any of
   Ctrl/Alt/Shift/Win.
2. **Nothing is installed on import or construction.** `start()` is the
   only thing that installs the mouse hook; `stop()` fully releases it and
   MUST restore magnification to 1.0 first — leaving the screen zoomed
   with no hook to unzoom it is the worst possible failure, so it is
   forbidden by construction and pinned by a test.
3. The mouse hook lives on its own thread with its own pump, exactly as
   the C# does. Nothing Tk, no app imports.
4. Ships **DISABLED by default**, same reason as the hotkey host.
5. Zoom is a full-screen transform centered on the pointer, clamped to a
   sane range (take the C#'s limits). Wheel-with-modifier is CONSUMED so
   the app underneath does not also scroll; wheel without the modifier
   passes through untouched.
6. If the Magnification API is unavailable or fails to initialize, the
   feature reports unavailable and installs nothing — never a half-armed
   hook.

## Probe

`if __name__ == "__main__":` — TWO parts, both safe:
1. Pure gesture demo, no hooks: feed a synthetic modifier-down, three
   wheel notches, modifier-up, and print each verdict and the resulting
   zoom factor.
2. Live check: report whether the Magnification API initializes, then —
   only if it does — apply a 1.5x zoom for ~1 second and return to 1.0,
   printing before/after factors, with the restore in a `finally` so an
   exception can never leave the screen magnified. State clearly in the
   output that the screen will briefly zoom.
