## Decisions already made

1. **Geometry is the deliverable.** The pure zone math must be complete
   and exhaustively tested with NO Windows calls — that is where the value
   and every edge case lives (odd pixel splits, constrained windows,
   repeat-press refinement, multi-monitor work areas).
2. **Placement is thin and optional.** A `place(hwnd, rect)` helper may use
   ctypes (SetWindowPos with SWP_NOZORDER|SWP_NOACTIVATE, and DPI-aware
   frame compensation the way `win/window_tracker.py` reads DWM extended
   frame bounds — read that module and reuse its conventions; do NOT
   modify it). Import ctypes inside functions only.
3. **No hotkeys, no hooks, no app wiring.** Chords belong to
   `win/keyboard_interception.py` and wiring is a later slice. This module
   exposes functions; it binds nothing.
4. Work areas come from `win/monitor_identity.py`-style enumeration or a
   passed-in rect — the pure functions must accept a work-area rect as an
   argument so they stay testable without a desktop.
