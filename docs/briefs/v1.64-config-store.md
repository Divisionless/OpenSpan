## ARCHITECTURAL DECISIONS ALREADY MADE (do not redesign)

1. **This store does NOT touch the product's existing config files.**
   `openspan_config.json`, `openspan_settings.json`, `openspan_keymap.json`,
   `bt_prefs.json`, `mode.txt` belong to the running app and must not be
   read, written, renamed or migrated by this module. The new store owns a
   NEW file, default name `esotericos_config.json`. Adoption of the legacy
   files is a separate future slice — say nothing about it in code beyond
   one docstring sentence.
2. **Runs-in-place paths, not %APPDATA%.** The product is portable (the exe
   anchors its data on its own folder). Resolution order for the data root:
   explicit constructor argument → `ESOTERICOS_DATA_DIR` env var → the
   product root (the parent of the directory holding this module). Inside
   that root: `config/`, `data/`, `logs/` as in the C#. No machine-specific
   literal anywhere in the source.
3. Keep the C# contract verbatim in behavior: human-readable JSON;
   `schemaVersion`; whole-document round-trip preservation (fields written
   by newer builds survive untouched); atomic write (temp + os.replace);
   automatic backup before any migration; corrupt file preserved (never
   deleted) then last-good fallback then safe defaults; a newer schema on
   disk makes the store write-protected rather than clobbering; the
   `hardware` section is the only machine-specific area; secrets never
   written.

## API (mirror the C# surface, pythonic names)

`ConfigStore(root=None, migrations=None)` with `.load_result` →
`ConfigLoadResult(loaded_from_backup, using_defaults, problems)`;
`get_feature_enabled/set_feature_enabled`,
`get_feature_setting/set_feature_setting` (JSON-typed, fallback on bad
data), `get_shortcut_overrides/set_shortcut_overrides`,
`get_hardware_section`, `reset_feature`, `reset_all`, `export(path)`,
`import_(path)` (raises a clear error with the collected problems),
`save()`. A migration is any object with `from_version` and
`apply(root_dict)`. Thread-safe with one lock, as the C# is.

`if __name__ == "__main__":` probe — runs entirely inside a
`tempfile.TemporaryDirectory()` (NEVER the real product root): creates a
store, writes settings, saves, corrupts the file on purpose, reloads to
prove last-good recovery, runs a fake migration, prints each step's
outcome, exits 0.
