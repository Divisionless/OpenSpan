## The law of this feature

A hidden window that cannot be recovered is a lost window, and the old
program has an explicit rule about it: **windows on a monitor that
disappears are never left hidden**, and everything is restored on
shutdown. Port that discipline exactly and pin it with tests:

1. Every hide is recorded with enough identity to be undone.
2. `restore_all()` shows every window this module ever hid, and is
   idempotent.
3. A monitor going away restores its windows rather than orphaning them.
4. Construction and import hide NOTHING. Nothing happens until an
   explicit `enable()`.
5. `disable()` restores everything before releasing anything.
