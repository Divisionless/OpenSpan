## Module shape

- PURE CORE (no Windows imports at module level): WindowIdentity semantics
  and any filtering/matching rules the C# keeps in Core.
- WINDOWS FILL (ctypes inside functions): enumeration (EnumWindows +
  eligibility rules from WindowService), DWM attribute reads, and the
  WinEvent hook layer — constructed but installing NOTHING on import or
  construction; an explicit `start()` installs SetWinEventHook (the app
  wires it in a later slice). WinEvent callbacks must never raise (house
  law, see win/openspan.py ~3956: 0xc000041d).
- The model-follows-reality law from the old program: the tracker never
  invents state — it reports what the OS says, debounced storms and all.
- `if __name__ == "__main__":` probe — two parts: (1) enumerate the
  current desktop and print one line per eligible top-level window (class
  name + DWM bounds + cloaked flag; NO window titles — titles can carry
  personal content), plus a count of windows excluded by each rule; (2)
  install the WinEvent hook, pump ~3 seconds, print how many events
  arrived, uninstall, exit 0.
