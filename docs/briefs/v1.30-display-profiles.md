## Decisions already made (this feature can wreck a desk — read carefully)

1. **This module NEVER applies a display change on import, on
   construction, or from the probe.** Applying is one explicit function
   the app will call later. Doug's three-display desk is in active use;
   an accidental mode change is a serious regression, not a cosmetic one.
2. **Apply is plan-then-commit with mandatory revert.** Port the C#
   confirm-or-revert: compute a plan, apply it non-committally, and if no
   confirmation arrives inside the timeout, restore the previous
   arrangement. The revert path must be exercised by tests with a fake
   applier — never against real hardware.
3. **The applier is injected.** `apply_profile(profile, applier=...)`
   takes a callable that performs the actual mode change; the default
   real applier lives behind a separate factory function so every test
   and the probe use a fake. ctypes imports inside functions only.
4. Profiles are keyed by the monitor set's stable keys (from
   `monitor_identity`), never by DISPLAY names.

## Probe

the single real-applier factory function.
